# Changelog

All notable changes follow [Keep a Changelog](https://keepachangelog.com/en/1.1.0/).

## [1.0.0] - 2026-08-27

### Added

- World Bank ingestion with validation, retries, concurrency limits, raw lineage, and replay.
- Idempotent SQLAlchemy persistence for SQLite and PostgreSQL.
- Explainable base, growth, and resilience scoring scenarios.
- FastAPI ranking/history API with health, readiness, logs, and Prometheus metrics.
- Streamlit executive dashboard.
- dbt staging, fact, latest-value, and data-coverage models.
- Alembic migration, Docker Compose, CI, security automation, tests, and documentation.
